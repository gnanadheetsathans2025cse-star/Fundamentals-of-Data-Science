# Fundamentals of Data Science – Lab Experiments

## About
This repository contains the laboratory experiments carried out as part of the Fundamentals of Data Science (FDS) course. It focuses on learning and applying basic data science concepts through practical experiments using Python.

## Topics Covered
- Data Collection and Exploration
- Data Analysis and Visualization
- Data Preprocessing and Cleaning
- Statistical Analysis and Hypothesis Testing
- Exploratory Data Analysis (EDA)
- Data Encryption and Decryption
- Machine Learning Algorithms

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Learning Objectives
- Understand and analyze datasets.
- Visualize data using different charts and plots.
- Handle missing values and detect outliers.
- Apply statistical techniques to data.
- Explore basic machine learning algorithms.

## Repository Contents
This repository includes individual PDF records of the experiments for easy access, reference, and revision.

## Purpose
To develop practical knowledge of Data Science concepts and improve analytical skills through hands-on laboratory work.
